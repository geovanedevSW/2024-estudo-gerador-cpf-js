# Estudo: Gerador de CPF em JavaScript

Projeto de estudo para praticar JavaScript criando e validando números de CPF.

## Sobre o projeto

A ideia é gerar CPFs sintaticamente válidos, calculando os dígitos verificadores conforme as regras do CPF. O projeto não consulta bases oficiais e não verifica se um número pertence a uma pessoa.

## Funcionalidades

- [ ] Gerar um CPF válido para testes
- [ ] Validar os dígitos verificadores
- [ ] Exibir o CPF sem pontuação

## Tecnologias

- HTML
- CSS
- JavaScript
